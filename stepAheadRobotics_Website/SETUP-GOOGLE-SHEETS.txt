STEPAHEADROBOTICS - GOOGLE SHEETS CONNECTION

The website is prepared to send each Student Details enquiry to Google Sheets and then open WhatsApp. One-time setup is required using your Google account.

STEP 1 - CREATE THE SHEET
1. Open https://sheets.google.com and create a blank spreadsheet.
2. Name it: stepAheadRobotics Student Enquiries.
3. In the sheet, choose Extensions > Apps Script.

STEP 2 - ADD THE SCRIPT
1. Open the file GoogleSheets.gs included in this website folder.
2. Copy all its contents into the Apps Script editor (replace the starter code).
3. Click Save. You may name the Apps Script project stepAheadRobotics Enquiries.

STEP 3 - DEPLOY AS A WEB APP
1. In Apps Script, click Deploy > New deployment.
2. Click the gear icon / Select type and choose Web app.
3. Set 'Execute as' to Me.
4. Set 'Who has access' to Anyone.
5. Click Deploy and approve Google's authorization prompts.
6. Copy the Web app URL. It normally ends with /exec. Keep this URL private; do not post it publicly.

STEP 4 - CONNECT THE WEBSITE
1. Open contact.html in a text editor.
2. Find this line near the bottom:
   const GOOGLE_SHEETS_WEB_APP_URL = 'PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE';
3. Replace only the placeholder text with the Web app URL copied in Step 3, keeping the single quotes.
   Example format: const GOOGLE_SHEETS_WEB_APP_URL = 'https://script.google.com/macros/s/DEPLOYMENT_ID/exec';
4. Save contact.html and upload the complete website folder to your hosting provider.

STEP 5 - TEST
1. Open the live website Contact page.
2. Submit a test enquiry with sample details.
3. Confirm a new row appears in the 'Student Enquiries' tab in your Google Sheet.
4. Confirm the test enquiry appears in the Google Sheet.
5. Separately test the 'Submit to WhatsApp' button; WhatsApp opens with the details and the visitor must press Send.

IMPORTANT
- Google Sheets is connected only after you complete Steps 1-4 and put your own Web App URL into contact.html.
- The website uses the existing stepAheadRobotics WhatsApp destination already present in the supplied website.
- The browser uses a no-cors request, so the page cannot read Google's response to verify the row. Always confirm the first test in the Google Sheet.
- Do not share the Web App URL publicly. Anyone who has the URL may be able to submit rows to your sheet.
