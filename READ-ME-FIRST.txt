STEPAHEADROBOTICS WEBSITE – READ FIRST

1. Open index.html to preview the website. Upload the complete folder to your web host while keeping all files in the same folder.
2. The brand name has been changed throughout the website to stepAheadRobotics.
3. The Contact page has separate actions: Submit Enquiry (Google Sheets, after setup) and Submit to WhatsApp.
4. To enable Google Sheets, follow SETUP-GOOGLE-SHEETS.txt and paste your deployed Apps Script Web App URL into contact.html.
5. The Robotics Projects page lists projects at ₹99 each. Edit the PROJECTS array in robotics-projects.html. Add only project names and descriptions; the visitor selects a project number and sends a WhatsApp enquiry.
6. After receiving an enquiry, verify payment in your payment app/account before sending the project text file manually. Do not rely only on a payment screenshot.
7. The footer links to Privacy Policy, Terms & Conditions and Refund Policy. These are starter templates. A parent/legal guardian and an appropriate Indian professional should review them before publishing or accepting payments.
8. Keep Google Drive files and paid project materials private. Do not put private file links in public HTML.
9. The WhatsApp destination is configured in the website code as the existing enquiry number. The number is not printed as visible text on the page. Change it only if you control that WhatsApp account.

IMPORTANT: If the person operating this website is under 18, a parent or legal guardian should be responsible for business, payment, legal and customer-data decisions.

10. The Contact enquiry form now changes the Preferred Level dropdown based on the selected course. Robotics lists Beginner, Intermediate and Advanced (kit provided for every level); AI and Python show their specific level names. Every level is listed as a 6-month course.
